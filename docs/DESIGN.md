## Brand & Style

This design system expresses high-order intelligence, executive precision, and hyper-modern computation for enterprise AI orchestration. It pairs deep obsidian canvas depths with surgical, luminous photon accents to convey latent compute power waiting behind an elegant interface.

The design movement merges **Dark-Mode Glassmorphism** with **Technical Minimalism**:
- Translucent dark surface layers suspended over cosmic obsidian voids.
- Crisp 1px hairline structural borders simulating laser-etched precision glass.
- Directed glow fields, ambient luminescence, and pill-shaped interactive components.
- Monospaced telemetry accents contrasted against fluid, highly legible geometric sans typography.

The emotional signature is commanding, sovereign, quiet, and hyper-responsive—delivering immediate clarity to complex neural workflows without visual fatigue.

## Colors

The palette relies on absolute deep-space grounds contrasted with narrow, hyper-concentrated photonic highlights. 

### Canvas and Obsidian Neutrals
- **Canvas Base:** `#090D16` (Deepest backdrop void)
- **Surface Level 1:** `#0D111C` (Primary panel baseline)
- **Surface Level 2:** `#131826` (Floating cards and containers)
- **Surface Level 3 / Active:** `#1B2236` (Hover states and elevated overlays)
- **Hairline Borders:** `rgba(255, 255, 255, 0.08)` (Neutral structural wireframes)
- **Hairline Border Active:** `rgba(0, 240, 255, 0.35)` (Focused or energized bounds)

### Core Luminescence
- **Primary (Electric Cyan):** `#00F0FF` — Key system triggers, critical metrics, execution pathways, and active glowing states.
- **Secondary (Bioluminescent Indigo/Violet):** `#6366F1` to `#8B5CF6` — Neural nodes, dynamic pipelines, orchestration badges, and fluid gradient sweeps.
- **Tertiary (Quantum Emerald):** `#10B981` — Safe runtime telemetry, successful inference executions, and latency health.
- **Warning / Alert:** `#F43F5E` — Model drift, compute failure, and quota halts.

### Text Contrast Tiers
- **Text High-Contrast (Headings):** `#F8FAFC` (Pure optical crispness)
- **Text Body / Standard:** `#94A3B8` (Balanced mid-tone against deep backdrops)
- **Text Muted / Telemetry:** `#475569` (Subordinate metadata and inactive states)

## Typography

The type system blends structural geometric authority with machine-level precision:
- **Headlines (Plus Jakarta Sans):** Sculpted, contemporary curves that balance technical rigidity with modern elegance. Use tighter letter-spacing for headers to create high-density executive punch.
- **Body Text (Inter):** Highly legible, neutral workhorse engine tuned for dense analytics grids and multi-column prompt editors.
- **Data & Telemetry (JetBrains Mono):** Reserved for parameter counts, latency metrics (e.g., `42ms`), token tracking, tensor coordinates, and payload logs. Uppercase tracking is applied to micro-telemetry tokens.

## Layout & Spacing

The layout is built upon a 12-column adaptive fluid grid governed by strict 8pt atomic rhythms:
- **Desktop (1280px+):** 12-column fluid grid, 32px margins, 24px gutters. Structural sidebars default to 260px fixed width, with primary workspace and analytics canvases expanding fluidly.
- **Tablet (768px - 1279px):** 8-column layout, 24px margins, 16px gutters. Navigation collapses to an icon bar or overlay sheet.
- **Mobile (<768px):** 4-column layout, 16px margins, 16px gutters. Multi-metric dashboards reflow into swipeable or vertically stacked glass card strips.

Density is calibrated for high-throughput interfaces: micro spacing (`space-xs` and `space-sm`) handles internal card tags and inputs, while macro gaps (`space-lg` and `space-xl`) separate distinct data clusters and neural graph orchestrators.

## Elevation & Depth

Visual depth is achieved through optical filtration, luminance stacking, and laser-thin specular edges rather than muddy, pitch-black drop shadows:

1. **Backdrop Atmosphere:** Background canvases use radial gradients of deep violet `#6366F1` and cyan `#00F0FF` at `3%` to `6%` opacity with a heavy `120px` blur, establishing a faint bioluminescent undercurrent.
2. **Frosted Surface Tiers:**
   - **Level 1 (Dock & Sidebars):** `background: rgba(13, 17, 28, 0.75); backdrop-filter: blur(16px); border-right: 1px solid rgba(255, 255, 255, 0.06);`
   - **Level 2 (Cards & Panels):** `background: rgba(19, 24, 38, 0.65); backdrop-filter: blur(12px); border: 1px solid rgba(255, 255, 255, 0.08);`
   - **Level 3 (Modals & Overlays):** `background: rgba(27, 34, 54, 0.85); backdrop-filter: blur(24px); border: 1px solid rgba(255, 255, 255, 0.14);`
3. **Photonic Shadow Accents:**
   - **Ambient Rest:** `box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.45);`
   - **Luminescent Cyan Edge (Active/Hover):** `box-shadow: 0 0 0 1px rgba(0, 240, 255, 0.4), 0 8px 24px -4px rgba(0, 240, 255, 0.15);`
   - **Violet Accent Glow:** `box-shadow: 0 0 20px -2px rgba(99, 102, 241, 0.25);`

## Shapes

The design system employs precise, balanced roundedness (`0.5rem` / `8px` baseline) for structural components to retain an engineered, aerospace-grade aesthetic, shifting to full pill forms exclusively for interactive tags, status indicators, and micro-actions.

- **Standard Elements (8px / `rounded`):** Dashboard tiles, modal dialogues, input fields, telemetry panels, and code execution consoles.
- **Intermediate Modules (16px / `rounded-lg`):** High-level card wrappers, prompt builders, and playground containers.
- **Pill Elements (9999px / `full`):** Filter tags, prompt tokens, glowing status chips, model selector switches, and segmented controls.

## Components

### Buttons & Action Controls
- **Primary Luminescent Button:** Cyan-fill (`#00F0FF`) with midnight obsidian text (`#090D16`), weight 600, rounded-full. Hover triggers a diffuse photon flare: `box-shadow: 0 0 20px rgba(0, 240, 255, 0.45)`.
- **Secondary Glass Button:** Translucent base (`rgba(255, 255, 255, 0.04)`), 1px border (`rgba(255, 255, 255, 0.1)`), crisp white text (`#F8FAFC`). Hover transitions border to `rgba(99, 102, 241, 0.6)` and background to `rgba(99, 102, 241, 0.1)`.
- **Ghost/Micro Button:** Borderless, muted slate text (`#94A3B8`), hover reveals crisp cyan highlight text with `background: rgba(255, 255, 255, 0.03)`.

### Chips, Badges & Pill Tags
- **Model Status Chips:** Pill-shaped (`rounded-full`), padded `4px 10px`, typography in `label-telemetry`. Uses a 6px breathing dot indicator:
  - Active/Online: Green dot (`#10B981`) with box-glow `0 0 8px #10B981`.
  - Inferencing: Cyan dot (`#00F0FF`) with continuous subtle pulse.
  - Idle/Standby: Slate dot (`#475569`).
- **Telemetry Tag:** Dark translucent fill (`rgba(0, 0, 0, 0.3)`), border `1px solid rgba(255, 255, 255, 0.08)`, monospaced text for token usage and latency.

### Glass Cards & Containers
- Frosted dark panels featuring top-gradient specular borders (a 1px gradient line fading from `rgba(255, 255, 255, 0.15)` at the top center to transparent at the edges).
- Interactive card variants increase border illumination to `rgba(0, 240, 255, 0.3)` and scale up background brightness by 3% on cursor hover.

### Inputs & Prompt Enclosures
- Dark obsidian inset (`#090D16` at 80% opacity), inset shadow `inset 0 2px 4px rgba(0,0,0,0.5)`, outer border `1px solid rgba(255, 255, 255, 0.1)`.
- **Focus State:** Hairline border snaps to `#00F0FF` with a subtle external glow `0 0 12px rgba(0, 240, 255, 0.2)`. Placeholder typography styled in `#475569`.

### Checkboxes & Toggle Switches
- **Checkboxes:** 18px rounded (4px) frames. Active state fills with `#00F0FF`, presenting an obsidian checkmark with an ambient cyan drop-glow.
- **Toggles:** Pill-shaped track (`#131826` when off, `#6366F1` when on). Thumb is pure white `#FFFFFF` casting an elevation shadow of `0 2px 8px rgba(0, 0, 0, 0.5)`.

### Specialized AI Platform Modules
- **Neural Graph Node:** Glass container with violet border, showing node type, execution state, and input/output vector ports as glowing micro-rings.
- **Prompt Token Pill:** Removable inline pill tag with dismiss `×`, monospaced token count indicator, and soft secondary color tint.
- **Streaming Execution Console:** Full-width code block surface using JetBrains Mono, styled in dark obsidian `#070A10`, syntax-highlighted with electric cyan, bioluminescent violet, and quantum emerald tokens.
